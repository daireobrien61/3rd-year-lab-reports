# 3rd-year-lab-reports
Lab reports for each of the respective experiments are found in the folders. The style.sty file contains all the needed dependancies needed to rebuild each of the documents. All documents are compiled using pdfTeX, Version 3.141592653-2.6-1.40.28 (TeX Live 2025). 

Any related diagrams are stored in ~/images.
Any data is stored in ~/data.
